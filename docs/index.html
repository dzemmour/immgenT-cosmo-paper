This site documents the analysis behind immgenT: A Comprehensive Reference of Convergent T-cell States in the Mouse: an atlas of 682,935 mouse T cells from 734 samples across 80 experiments, profiled by single-cell RNA-seq, 128-plex CITE-seq and paired αβ TCR sequencing, and organised into eight lineages and 107 reproducible clusters.

Each page below covers one published figure. For every panel it shows the R code that produced it, the panel itself, and a caption stating what it shows.

What is and is not reproduced here

This repository covers the panels produced by the analysis code for this paper. A panel is listed as not reproduced when the input it needs is not part of the deposited dataset — an external study’s own embedding, a per-sample pseudobulk matrix, or a published gene signature obtained from another paper. Each figure page names its own gaps, and code/README.md gives the reason for each in the data provenance table.

Panels drawn outside R — the schematics in Figure 1a, Figure 1c and Figure 9a — have no code and are not shown.

Reproducing these figures

Every page above is generated by a single R script in script/, which sources shared plotting and data-loading helpers from code/R/. To regenerate a figure, run from the repository root:

Rscript script/Figure4.R

Panels are written as one PDF per panel into figures/<figure>/. The pages on this site display PNGs converted from those PDFs by Rscript script/render_site_assets.R, so the site cannot drift from the panel set the scripts produced; the code shown on each page is displayed, not re-executed when the site is built.

The input data (~3.9 GB of Seurat objects and cached intermediates) is not in this repository. It is deposited on Zenodo; download it and unpack it into data/ at the repository root. code/README.md lists every file, what reads it, and where it comes from.
